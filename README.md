This website is a simple personal site created for COSC 219 Lab 1.
It includes a home page, an about page, and a projects page.

Live site:
https://nullstart.github.io/cosc219-site/

The problem I encountered is why it is not possible to directly embed -figure- within -p-.(I cannot use <> here.)

## Lab 2
A shared external CSS stylesheet was added to uniformly beautify all four pages. The project table was updated, and navigation functionality was added to the contact page.

### Styling Decision
Originally, I was planning to choose a style similar to VS Code with a black background, but that would be not very good for the eyes. In the end, the blue and white style was chosen.

## AI Use

I asked ChatGPT to answer this question, and its answer is: -figure- is an independent block-level/semantic content that will terminate the <p> tag prematurely.
